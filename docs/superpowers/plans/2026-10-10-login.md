# 登录模块 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 intuly-mobile 中实现手机号验证码登录 + 账号密码登录（含滑块验证），登录后进入首页占位页。

**Architecture:** feature-first 分层：`core/`（主题、网络）+ `features/auth`（data / application / presentation）+ `features/home` + `router/`。Dio 拦截器统一处理 header、token 和业务 status；Riverpod 3 的 `Notifier` 持有会话；go_router 依据会话做重定向。

**Tech Stack:** Flutter 3.47.7 / Dart ^3.13.5，flutter_riverpod 3.4.3，go_router 18.0.2，dio 5.11.1，flutter_secure_storage 11.2.0，flutter_svg 2.3.0，url_launcher 6.3.3。

**Spec:** `docs/superpowers/specs/2026-10-10-login-design.md`

## Global Constraints

- 不执行任何 `git add` / `git commit`（用户全局规则；本项目也不是 git 仓库）。
- 依赖使用精确版本（不带 `^`），见 Task 1。
- 不使用 riverpod 代码生成（无 build_runner），用手写 `Notifier` / `Provider`。这是相对 spec 的有意简化。
- 滑块状态放在弹窗 `State` 内部（作用域只在弹窗内），不单独建 `SlideCaptchaNotifier`。这也是相对 spec 的简化。
- baseURL `https://www.intuly.com/api`；Header `AI-Api-ClientId: 101409740478767510`、`AI-Api-Version: v1.0.0`；登录后加 `Authorization: Bearer <token>`。
- `loginType` 固定 `'2'`（移动端）；`smsType` 固定 `1`（登录）。
- 业务状态码读响应 body 的 `status`：200/201 成功；401/405/409 退出登录；403 账号或密码错误；301 封禁 / 302 冻结 / 303 违规。
- Token 只存 flutter_secure_storage，不打印到日志。
- 颜色：主色 `#0057FF`，标题 `#1D2129`，次级 `#4D5562`，辅助 `#868F9C`，占位 `#CACCD0`，输入框底 `#F9F9FA`，输入框描边 `#F2F3F5`，复选框描边 `#E5E6EB`，滑块轨道 `#DEDFE0`。
- 输入框高 44、圆角 12.8（取自设计稿 SVG 路径，spec 写的 4px 有误）；主按钮高 44、圆角 8。
- 滑块 `moveWidth = round(拖动距离 / scale)`，`scale = 渲染宽度 / 原图 width`（与 Web 端 `custom.vue` 一致）。
- 每个任务结束都要跑 `flutter analyze` 和该任务的测试，全绿才算完成。

```dart
import 'dart:convert';
import 'dart:typed_data';

import 'package:dio/dio.dart';

/// 按路径返回预设响应，并记录所有请求（options.data 保留原始 Map）。
class FakeHttpAdapter implements HttpClientAdapter {
  final List<RequestOptions> requests = [];
  final Map<String, ({int httpStatus, Object? body})> _routes = {};

  void on(String path, {int httpStatus = 200, required Object? body}) {
    _routes[path] = (httpStatus: httpStatus, body: body);
  }

  @override
  Future<ResponseBody> fetch(
    RequestOptions options,
    Stream<Uint8List>? requestStream,
    Future<void>? cancelFuture,
  ) async {
    requests.add(options);
    final route = _routes[options.path];
    if (route == null) {
      throw StateError('FakeHttpAdapter: 未注册路径 ${options.path}');
    }
    return ResponseBody.fromString(
      jsonEncode(route.body),
      route.httpStatus,
      headers: {
        Headers.contentTypeHeader: [Headers.jsonContentType],
      },
    );
  }

  @override
  void close({bool force = false}) {}
}
```

- [ ] **Step 2: 写失败测试 `test/core/network/dio_client_test.dart`**

```dart
import 'package:dio/dio.dart';
import 'package:flutter_test/flutter_test.dart';
import 'package:intuly/core/network/api_exception.dart';
import 'package:intuly/core/network/dio_client.dart';

import '../../helpers/fake_http_adapter.dart';

void main() {
  late FakeHttpAdapter adapter;
  late Dio dio;
  String? token;
  var unauthorizedCalls = 0;

  setUp(() {
    adapter = FakeHttpAdapter();
    token = null;
    unauthorizedCalls = 0;
    dio = createDio(
      readToken: () => token,
      onUnauthorized: () => unauthorizedCalls++,
      adapter: adapter,
    );
  });

  test('带公共 header，未登录时不带 Authorization', () async {
    adapter.on('/ping', body: {'status': 200, 'data': 'ok'});
    await dio.post<Object?>('/ping');
    final h = adapter.requests.single.headers;
    expect(h['AI-Api-ClientId'], '101409740478767510');
    expect(h['AI-Api-Version'], 'v1.0.0');
    expect(h.containsKey('Authorization'), isFalse);
    expect(adapter.requests.single.baseUrl, 'https://www.intuly.com/api');
  });

  test('登录后带 Bearer token', () async {
    token = 'tk-123';
    adapter.on('/ping', body: {'status': 200, 'data': 'ok'});
    await dio.post<Object?>('/ping');
    expect(adapter.requests.single.headers['Authorization'], 'Bearer tk-123');
  });

  test('body.status 201 视为成功', () async {
    adapter.on('/ping', body: {'status': 201, 'data': 'x', 'message': 'm'});
    final res = await dio.post<Map<String, dynamic>>('/ping');
    expect(res.data!['status'], 201);
  });

  test('body.status 非 2xx 抛 ApiException，带 status 和 message', () async {
    adapter.on('/ping', body: {'status': 403, 'message': '账号或密码错误'});
    await expectLater(
      dio.post<Object?>('/ping'),
      throwsA(isA<DioException>().having((e) => e.error, 'error',
          isA<ApiException>()
              .having((a) => a.status, 'status', 403)
              .having((a) => a.isWrongCredentials, 'wrong', isTrue))),
    );
    expect(unauthorizedCalls, 0);
  });
```

```dart
import 'package:dio/dio.dart';

/// 封装业务状态码和错误消息（优先读响应 body.status）。
class ApiException implements Exception {
  final int? status;
  final String message;

  ApiException({required this.status, required this.message});

  /// 401/405/409 视为未授权，调方需清会话。
  bool get isUnauthorized => [401, 405, 409].contains(status);

  /// 403 账号或密码错误。
  bool get isWrongCredentials => status == 403;

  /// 301 封禁 / 302 冻结 / 303 违规。
  bool get isAccountDisabled => status != null && [301, 302, 303].contains(status);

  /// 从 DioException 提取。优先取 response.data['status']；回退取 HTTP status。
  /// message 优先取 response.data['message']；回退取 HTTP status 对应默认值。
  static ApiException fromDio(DioException e) {
    final data = e.response?.data;
    int? bodyStatus;
    String? bodyMessage;
    if (data is Map<String, dynamic>) {
      bodyStatus = data['status'] as int?;
      bodyMessage = data['message'] as String?;
    }
    final status = bodyStatus ?? e.response?.statusCode;
    final message = bodyMessage ?? _defaultMessage(status);
    return ApiException(status: status, message: message);
  }

  static String _defaultMessage(int? status) {
    switch (status) {
      case 403: return '账号或密码错误';
      case 401: case 405: case 409: return '登录已过期，请重新登录';
      default: return '网络错误，请稍后重试';
    }
  }

  @override
  String toString() => 'ApiException(status: $status, message: $message)';
}
```

`onResponse` 里发现 body.status 非 2xx 时，在 reject 之前先调用 `onUnauthorized`。`onError` 收到的错误如果已经包了 `ApiException`，就直接放行，不再调第二次。这样无论 Dio 会不会把 reject 再交给同一个拦截器的 onError，`onUnauthorized` 都只会触发一次。

```dart
import 'package:dio/dio.dart';

import '../../config/env_config.dart';
import 'api_exception.dart';

Dio createDio({
  required String? Function() readToken,
  required void Function() onUnauthorized,
  HttpClientAdapter? adapter,
}) {
  final dio = Dio(BaseOptions(
    baseUrl: EnvConfig.baseUrl,
    connectTimeout: const Duration(seconds: 15),
    receiveTimeout: const Duration(seconds: 15),
    contentType: Headers.jsonContentType,
    responseType: ResponseType.json,
    headers: {
      'AI-Api-ClientId': EnvConfig.clientId,
      'AI-Api-Version': EnvConfig.apiVersion,
    },
  ));
  if (adapter != null) dio.httpClientAdapter = adapter;

  dio.interceptors.add(InterceptorsWrapper(
    onRequest: (options, handler) {
      final token = readToken();
      if (token != null && token.isNotEmpty) {
        options.headers['Authorization'] = 'Bearer $token';
      }
      handler.next(options);
    },
    onResponse: (response, handler) {
      final data = response.data;
      final status = data is Map<String, dynamic> ? data['status'] : null;
      if (status is int && (status < 200 || status > 299)) {
        final apiError = ApiException(
          status: status,
          message: (data as Map<String, dynamic>)['message'] as String? ??
              ApiException.fromDio(DioException(
                requestOptions: response.requestOptions,
                response: response,
              )).message,
        );
        if (apiError.isUnauthorized) onUnauthorized();
        handler.reject(DioException(
          requestOptions: response.requestOptions,
          response: response,
          type: DioExceptionType.badResponse,
          error: apiError,
        ));
        return;
      }
      handler.next(response);
    },
    onError: (err, handler) {
      if (err.error is ApiException) {
        handler.next(err);
        return;
      }
      final apiError = ApiException.fromDio(err);
      if (apiError.isUnauthorized) onUnauthorized();
      handler.next(err.copyWith(error: apiError));
    },
  ));
  return dio;
}
```

```dart
class DioAuthRepository implements AuthRepository {
  static const int _smsTypeLogin = 1;
  static const String _loginTypeMobile = '2';

  final Dio _dio;
  DioAuthRepository(this._dio);

  /// 统一 POST：DioException 转成 ApiException，返回 body Map。
  Future<Map<String, dynamic>> _post(String path, Map<String, dynamic> data) async {
    try {
      final res = await _dio.post<Map<String, dynamic>>(path, data: data);
      return res.data ?? const {};
    } on DioException catch (e) {
      final err = e.error;
      throw err is ApiException ? err : ApiException.fromDio(e);
    }
  }

  @override
  Future<SlideChallenge> fetchSlide(String loginUser) async {
    final body = await _post('/login/ai/slide',
        {'loginUser': loginUser, 'smsType': _smsTypeLogin});
    final data = body['data'];
    if (data is! Map<String, dynamic>) {
      throw ApiException(status: body['status'] as int?, message: '获取滑块失败，请重试');
    }
    try {
      return SlideChallenge.fromJson(data);
    } on FormatException {
      throw ApiException(status: null, message: '获取滑块失败，请重试');
    }
  }

  @override
  Future<SlideCheckResult> checkSlide({
    required String loginUser, required String captchaId, required int moveWidth}) async {
    final body = await _post('/login/ai/checkSlide', {
      'loginUser': loginUser,
      'imgCaptchaId': captchaId,
      'moveWidth': moveWidth.toString(),
      'smsType': _smsTypeLogin,
    });
    final data = body['data'] as Map<String, dynamic>? ?? const {};
    return SlideCheckResult(
      passed: data['checkResult'] == true,
      loginSlide: data['loginSlide'] as String?,
      errorCount: (data['errorCnt'] as num?)?.toInt() ?? 0,
    );
  }

  @override
  Future<String> sendSms({required String phone, required String loginSlide}) async {
    final body = await _post('/login/ai/sendSms',
        {'phone': phone, 'loginSlide': loginSlide, 'smsType': _smsTypeLogin});
    final data = body['data'];
    return body['status'] == 201 && data is String && data.isNotEmpty ? data : loginSlide;
  }

  @override
  Future<String> loginWithPhone({
    required String phone, required String code, required String loginSlide}) async {
    final body = await _post('/login/ai/phone', {
```

```dart
class Session {
  final String token;
  final String account;
  const Session({required this.token, required this.account});
}

abstract class SessionStorage {
  Future<Session?> read();
  Future<void> write(Session session);
  Future<void> clear();
}

class SecureSessionStorage implements SessionStorage {
  static const _keyToken = 'token';
  static const _keyAccount = 'account';
  final FlutterSecureStorage _storage;
  SecureSessionStorage(this._storage);

  @override
  Future<Session?> read() async {
    final token = await _storage.read(key: _keyToken);
    final account = await _storage.read(key: _keyAccount);
    return token != null && account != null ? Session(token: token, account: account) : null;
  }

  @override
  Future<void> write(Session session) async {
    await _storage.write(key: _keyToken, value: session.token);
    await _storage.write(key: _keyAccount, value: session.account);
  }

  @override
  Future<void> clear() async {
    await _storage.delete(key: _keyToken);
    await _storage.delete(key: _keyAccount);
  }
}
```

```dart
import 'dart:math' as math;

import '../../data/models/slide_challenge.dart';

/// 原图像素 ↔ 渲染逻辑像素的换算。与 Web 端 custom.vue 一致：
/// scale = 渲染宽 / 原图宽；moveWidth = round(拖动距离 / scale)。
class SlideGeometry {
  static const double knobSize = 44;

  final double renderWidth;
  final double scale;
  final double renderHeight;
  final double pieceWidth;
  final double pieceHeight;
  final double pieceTop;

  SlideGeometry(SlideChallenge c, this.renderWidth)
      : scale = renderWidth / c.width,
        renderHeight = c.height * (renderWidth / c.width),
        pieceWidth = c.pieceWidth * (renderWidth / c.width),
        pieceHeight = c.pieceHeight * (renderWidth / c.width),
        pieceTop = c.pieceTop * (renderWidth / c.width);

  double get maxOffset => math.max(0, renderWidth - math.max(pieceWidth, knobSize));

  double clamp(double offset) => offset.clamp(0, maxOffset).toDouble();

  int moveWidthFor(double offset) => (offset / scale).round();
}
```

class _SlideCaptchaDialogState extends ConsumerState<SlideCaptchaDialog> {
  static const _hint = '请拖动滑块完成拼图';
  static const _retryHint = '未对准，请重试';

  SlideChallenge? _challenge;
  String? _loadError;
  bool _loading = true;
  bool _checking = false;
  double _offset = 0;
  String _trackText = _hint;
  Timer? _resetTimer;

  @override
  void initState() {
    super.initState();
    _fetch(); // 首个 await 之前不调用 setState
  }

  @override
  void dispose() {
    _resetTimer?.cancel();
    super.dispose();
  }

  void _reload() {
    setState(() {
      _loading = true;
      _loadError = null;
      _offset = 0;
      _trackText = _hint;
    });
    _fetch();
  }

  Future<void> _fetch() async {
    try {
      final c = await ref.read(authRepoProvider).fetchSlide(widget.loginUser);
      if (!mounted) return;
      setState(() { _challenge = c; _loading = false; });
    } on ApiException catch (e) {
      if (!mounted) return;
      setState(() { _loadError = e.message; _loading = false; });
    }
  }

  Future<void> _submit(SlideGeometry g) async {
    final c = _challenge;
    if (c == null || _checking) return;
    setState(() => _checking = true);
    try {
      final r = await ref.read(authRepoProvider).checkSlide(
        loginUser: widget.loginUser, captchaId: c.captchaId, moveWidth: g.moveWidthFor(_offset));
      if (!mounted) return;
      if (r.passed && r.loginSlide != null) {
        Navigator.of(context).pop(r.loginSlide);
        return;
      }
      _onFailed(_retryHint, reload: r.errorCount >= 3);
    } on ApiException catch (e) {
      if (mounted) _onFailed(e.message, reload: true);
    } finally {
      if (mounted) setState(() => _checking = false);
    }
  }

  void _onFailed(String text, {required bool reload}) {
    setState(() => _trackText = text);
    _resetTimer?.cancel();
    _resetTimer = Timer(const Duration(seconds: 1), () {
      if (!mounted) return;
      if (reload) {
        _reload();
      } else {
        setState(() { _offset = 0; _trackText = _hint; });
      }
    });
  }

```dart
class PhoneLoginForm extends StatefulWidget {
  const PhoneLoginForm({super.key, required this.agreed, required this.onAgreedChanged});
  final bool agreed;
  final ValueChanged<bool> onAgreedChanged;
  @override State<PhoneLoginForm> createState() => _PhoneLoginFormState();
}

class _PhoneLoginFormState extends State<PhoneLoginForm> {
  static final _phoneRe = RegExp(r'^1[3-9]\d{9}$');
  final _phoneCtrl = TextEditingController();
  final _codeCtrl = TextEditingController();
  String? _loginSlide, _smsSentPhone;
  bool _sending = false, _submitting = false;
  int _countdown = 0;
  Timer? _timer;

  @override void initState() {
    super.initState();
    _phoneCtrl.addListener(_onChanged);
    _codeCtrl.addListener(_onChanged);
  }
  @override void dispose() {
    _timer?.cancel();
    _phoneCtrl.dispose();
    _codeCtrl.dispose();
    super.dispose();
  }

  void _onChanged() => setState(() {});
  bool get _phoneValid => _phoneRe.hasMatch(_phoneCtrl.text.trim());
  bool get _canSend => _phoneValid && _countdown == 0 && !_sending;
  bool get _canSubmit => _phoneValid && _codeCtrl.text.trim().length == 6 && !_submitting;

  Future<void> _sendCode() async {
    if (!_canSend || !mounted) return;
    final phone = _phoneCtrl.text.trim();
    setState(() => _sending = true);
    try {
      final slide = await ref.read(slideVerifierProvider)(context, phone);
      if (!mounted || slide == null) return;
      final ls = await ref.read(authRepoProvider).sendSms(phone: phone, loginSlide: slide);
      if (!mounted) return;
      setState(() { _loginSlide = ls; _smsSentPhone = phone; _countdown = 60; });
      _timer?.cancel();
      _timer = Timer.periodic(const Duration(seconds: 1), (_) {
        if (!mounted || _countdown <= 0) { _timer?.cancel(); return; }
        setState(() => _countdown--);
      });
      if (mounted) showLoginToast(context, '验证码已发送');
    } on ApiException catch (e) {
      if (mounted) await showLoginError(context, e);
    } finally {
      if (mounted) setState(() => _sending = false);
    }
  }

  Future<void> _submit() async {
    if (!_canSubmit) return;
    if (!widget.agreed) {
      showLoginToast(context, '请先同意用户协议'); return;
    }
    final phone = _phoneCtrl.text.trim(), code = _codeCtrl.text.trim(), slide = _loginSlide;
    if (slide == null || _smsSentPhone != phone) {
      showLoginToast(context, '请先获取验证码'); return;
    }
    setState(() => _submitting = true);
    try {
      await ref.read(authProvider.notifier).loginWithPhone(phone, code, slide);
    } on ApiException catch (e) {
      if (mounted) await showLoginError(context, e);
    } finally {
      if (mounted) setState(() => _submitting = false);
    }
  }

  @override Widget build(BuildContext context) {
    // 完整布局：标题 "欢迎来到Intuly"、提示 "未注册手机号将自动注册"、
    // 手机号输入框(key: phone-input, +86前缀)、验证码输入框(key: code-input, 右侧SMS按钮)、
    // 登录按钮、协议行。间距参考设计稿。实施时补全。
```
